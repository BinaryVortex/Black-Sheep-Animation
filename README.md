# Black Sheep Animation

A playful CSS and JavaScript animation of a black sheep built with plain HTML, CSS and a touch of JavaScript.

![Demo screenshot](./Screenshot%202024-08-30%20105927.png)

## Overview

This small project showcases an animated black sheep using modern CSS techniques (transforms, keyframes) and minimal JavaScript to control or enhance the animation. It's intended as a lightweight demo and a starting point for learning CSS animation.

## Features

- Smooth sheep animation created with CSS keyframes
- Simple, easy-to-read HTML and CSS structure
- No build tools required — just open the HTML file in a browser

## Built With

- HTML
- CSS
- JavaScript (minimal)

## How to Run

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Black-Sheep-Animation.git

2. Open `index.html` in your browser (double-click or use `file://` path).

That's it — the animation runs in modern browsers without additional setup.

## File Structure

- `index.html` — main demo page
- `style.css` — all styles and animations
- `Screenshot 2024-08-30 105927.png` — demo screenshot used in this README
